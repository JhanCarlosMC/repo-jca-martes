# Repositorio Jovenes Creativos - Sesion Martes

Este es el repositorio que va a guardar toda la informacion de las clases realizadas
durante el curso de las sesiones del dia martes.

## Temas Tratados

1. Git - Github
    - .gitignore = Sirve para que git no tenga en cuenta archivos para los commits
    - Casos comunes 
        1. Archivos/carpetas propios del sistema.
        2. Archivos/carpetas metadata. (Informacion necesaria para la ejecucion local del proyecto)
        3. Archivos/carpetas generados por el uso de IA.
2. HTML
    - Estructura de nuestra pagina
    - Contenido y organizacion de este mismo
    - Estructura del HTML: Etiquetas
3. CSS
    - El estilo del contenido de la pagina
    - Distribucion visual de la pagina y sus elementos
    - Estructura del CSS: Selectores - propiedad y valores
